# 爱格 移动版

一个纯 Java 写的手机端智能体客户端，面向安卓 6 及以上的老设备优化。它在端侧跑一套"计划 → 工具调用 → 总结"的本地引擎，不依赖网络，会话、工具、配置都能正常用；程序一旦崩溃会自动跳到崩溃页，日志可一键复制发回开发侧。

> 关键词：安卓 6、Java 移动端、AI agent、端侧推理、企业级 UI、崩溃兜底、自适应图标、Material Design、老机适配、纯 Java 无 Kotlin、低 API 兼容、会话管理、工具插件、个性化主题

## 特点

- **兼容老机**：最低支持安卓 6（API 23），目标 API 34，全程只用 Java，没有引入 Kotlin。
- **端侧可用**：会话、工具开关、运行配置、系统诊断四大功能页都在手机上直接跑，本地引擎离线产出可查的轨迹。
- **崩溃兜底**：任何未捕获的异常都会自动进入崩溃页，展示可读日志，底部带"复制日志 / 分享 / 返回首页"三个按钮。
- **企业风界面**：统一的深色导航蓝配色，卡片式布局，深浅色双主题，视觉克制。
- **个性化**：主题深浅色、四种强调色、字号缩放、起始页、震动反馈、摇一摇抓日志，全部可持久化。
- **性能取向**：功能页懒加载，磁盘读写全部丢到后台线程，主线程不碰 IO，开启大堆。

## 目录结构

```
AgenzMobile/
├─ app/
│  ├─ build.gradle          模块配置（签名、最低/目标 API）
│  ├─ src/main/java/com/agenz/mobile/
│  │  ├─ AgenApplication.java   启动入口：装崩溃兜底、套主题、后台读存档
│  │  ├─ CrashHandler.java      全局未捕获异常处理，自动跳崩溃页
│  │  ├─ data/                  本地引擎与持久化
│  │  ├─ model/                 数据壳（会话/消息/工具/配置）
│  │  └─ ui/                    各页面
│  └─ src/main/res/             界面资源（布局/主题/图标/矢量）
├─ build.gradle              根工程
├─ settings.gradle           仓库源（走国内镜像）
└─ gradle/
```

## 构建

需要 JDK 17 和 Android SDK（platform-34、build-tools 34）。本工程的仓库源已配成国内镜像，拉依赖较快。

```bash
# 编译调试包
gradle :app:assembleDebug

# 编译并签名发布包
gradle :app:assembleRelease
```

产物在 `app/build/outputs/apk/` 下。签名配置写在 `app/build.gradle`，使用仓库内的 `gradle/agenz-release.keystore`；正式上架前请替换成自己的签名库并改掉密码。

## 关于本地引擎

会话页里跑任务时，引擎会把当前启用的工具逐个执行一遍，拼成"计划 → 工具 → 总结"的轨迹显示在详情页。这套是离线的、可查的；要接入真实后端，只需在 `AgentBackend.localEngine` 这里换成真实的网络调用即可。

## 崩溃日志

崩溃页的日志包含时间、系统版本、设备型号和完整堆栈。点日志区、或点底部"复制日志"，都会把整段写进剪贴板，直接发给开发侧即可。
