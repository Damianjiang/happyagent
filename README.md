# Happy Agent · 爱思办公手机端

**Happy Agent** 是一个用**纯 Java** 写的手机端智能体（agent）客户端，专为**安卓 6（API 23）及以上的老设备**做了全面适配。它把「会话管理、工具/插件、运行配置、系统诊断」四大能力搬到手机上，在端侧离线跑通一套 **计划 → 工具调用 → 总结** 的 agent 执行引擎，不依赖网络。程序崩溃不会闪退，而是**自动进入崩溃页**，日志可一键复制发回开发侧。图标是一枚黄色微笑圆点，界面是企业风。

> 关键词：安卓 6、老机适配、纯 Java、无 Kotlin、端侧 agent、离线智能体、本地推理、崩溃兜底、企业风 UI、Material 3、深色模式、自适应图标、会话管理、工具插件、个性化主题、低 API 兼容、minSdk 23、低内存优化

---

## 一、它是什么 / 解决什么问题

| 场景 | Happy Agent 的做法 |
| --- | --- |
| 想在老手机上用一个 agent 客户端 | 最低 API 23，全程 Java，无 Kotlin 依赖，老机流畅 |
| 想在离线环境跑任务 | 端侧引擎「计划 → 工具 → 总结」，不依赖网络 |
| 崩溃了找不到原因 | 自动跳崩溃页，日志一键复制/分享 |
| 想要简洁克制的界面 | 企业风：统一导航蓝、卡片式布局、品牌渐变顶栏 |
| 想要个性化的 App | 深浅色、4 种强调色、字号缩放、起始页、震动、摇一摇抓日志 |

## 二、特色功能（逐条讲透）

### 1. 会话管理（Sessions）
- 列出所有 agent 会话，每行带**状态徽章**（运行中 / 已完成 / 失败），一眼看清哪个任务在跑、哪个跑完了、哪个挂了。
- 点进详情页：输入任务 → 点「运行」→ 本地引擎离线执行 → 下方展示完整的「计划 → 工具 → 总结」**执行轨迹**，每一步调了哪个工具、输出了什么，全部可见可查。
- 右下角 **+** 号随时新建一个会话，互不干扰。
- 会话数据**持久化**在设备上，重启 App 不丢。

### 2. 工具 / 插件（Tools）
- 内置一套端侧工具集：代码检索、文件操作、Shell 沙箱、HTTP、上下文加载、记忆等。
- 行内开关**即时生效**，影响下一次任务会调用哪些工具；关掉某工具后，它的输出就不会再出现在轨迹里。
- 点进工具详情页可看完整说明并单独启停，和原版插件的用法一致。

### 3. 运行配置（Config）
- 调整**模型、温度（0~20）、最大 token、自动提交、工作目录**等运行参数，保存后下次任务直接套用。
- 配置同样持久化，改一次长期生效。

### 4. 系统诊断（Reports）
- 一眼看清系统状态：**会话总数、启用/停用工具数、当前模型、最近更新时间**，方便快速定位"现在系统处于什么状态"。

### 5. 崩溃兜底（核心卖点）
- **全局未捕获异常处理**：任意线程上的崩溃都会**自动进入崩溃页**，不白屏、不闪退。
- 崩溃页展示**可读日志**（时间、系统版本、设备型号、完整堆栈），底部三个按钮：
  - **复制日志**：整段写进剪贴板，直接发给开发侧定位。
  - **分享**：用系统分享面板转发。
  - **返回首页**：一键冷启一个干净实例，继续用。

### 6. 企业风界面 + 个性化
- 统一的导航蓝配色、卡片式布局、**品牌渐变顶栏**，深浅色双主题，视觉克制、层级清晰。
- 设置页可改（全部持久化，下次启动沿用）：
  - 深浅色主题（跟随系统 / 手动）
  - 4 种强调色（蓝 / 青 / 紫 / 玫红）
  - 字号缩放（拖滑块即时套用）
  - 起始停留页（会话页 or 工具页）
  - 震动反馈
  - 摇一摇抓取日志（方便随时报问题）

## 三、安装

1. 到 [Releases](https://github.com/Damianjiang/happyagent/releases) 下载最新的 `HappyAgent-v1.0-release.apk`（已 v1+v2 签名）。
2. 传到手机，点安装。
3. 若提示"未知来源应用"，去系统设置里允许安装未知来源 App，再装一次即可。
4. 安装完成，桌面图标是一枚**黄色微笑圆点**（安卓 7+ 为自适应图标，安卓 6 回退到 mipmap）。

## 四、5 分钟上手

1. **打开 App** → 默认进入「会话」页，能看到一条欢迎会话。
2. 点右下角 **+** → 进入新建的会话详情页。
3. 在输入框写一个任务（例如"整理一份项目周报"），点「运行」。
4. 稍等片刻，下方「结果」区会展示本地引擎的**计划 → 工具 → 总结**轨迹。
5. 去「工具」页开/关你希望参与执行的工具，再跑一次，轨迹会随之变化。
6. 去「配置」页改模型/温度，「保存」后生效。
7. 去「诊断」页查看当前会话数、工具启用数、当前模型。

## 五、崩溃日志怎么用

- 任意线程崩溃 → 自动进入崩溃页，展示完整日志。
- 点日志区，或点底部「复制日志」，整段写进剪贴板，直接发给开发侧定位。
- 「分享」按钮可用系统分享面板转发；「返回首页」一键冷启干净实例。

## 六、面向老设备做了哪些事

- 最低 API 23（安卓 6），目标 API 34；**全程只用 Java，无 Kotlin**。
- 功能页**懒加载**：首次点开才创建 Fragment，之后切换很轻。
- 所有磁盘读写丢到**后台线程**，主线程不碰 IO。
- 会话页轮询在 Activity 销毁时正确清理，**避免内存泄漏**。
- 规避了 API 26+ 才有的方法（如 `String.join`），**保证安卓 6 实机不崩**。
- 开启大堆，降低老机 OOM 概率。

## 七、架构说明

```
app/
├─ build.gradle          模块配置（签名、最低/目标 API）
├─ src/main/java/com/happyagent/mobile/
│  ├─ HappyAgentApplication.java   启动入口：装崩溃兜底、套主题、后台读存档

│  ├─ data/                        本地 agent 引擎与持久化
│  ├─ model/                       数据壳（会话 / 消息 / 工具 / 配置）
│  └─ ui/                          各页面（主界面、崩溃页、详情、设置…）
└─ src/main/res/                  界面资源（布局 / 主题 / 图标 / 矢量）
assets/
└─ happy_agent_icon.png           应用图标（黄色微笑圆点）
build.gradle                     根工程
settings.gradle                  仓库源（走国内镜像）
gradle/
```

## 八、如何接入真实后端

当前本地引擎是**离线、可查**的演示实现（`AgentBackend.localEngine`）。要接真实模型/后端，只需把这个方法替换成你的真实网络调用，其余的会话/工具/配置/崩溃兜底全部复用。

## 九、从源码构建

需要 **JDK 17** 和 **Android SDK**（platform-34、build-tools 34）。本工程仓库源已配成国内镜像，拉依赖较快。

```bash
# 调试包
gradle :app:assembleDebug

# 发布包（带签名）
gradle :app:assembleRelease
```

产物在 `app/build/outputs/apk/` 下。签名配置写在 `app/build.gradle`；发布库存在 `gradle/`，正式上架前请替换成你自己的签名库并改掉密码。

## 十、常见问题

**Q：最低支持什么系统？**
A：安卓 6（API 23）及以上。已在低 API 上规避所有 26+ 方法。

**Q：需要联网吗？**
A：不需要，端侧离线即可跑通任务。接真实后端才需要网络。

**Q：崩溃了怎么办？**
A：不会闪退，自动进崩溃页，一键复制日志发开发。

**Q：图标为什么是自适应的？**
A：安卓 7+ 显示自适应图标，安卓 6 回退到 mipmap 位图，都做了。
