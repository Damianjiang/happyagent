# 爱思办公（爱思 移动版）

一个用纯 Java 写的手机端智能体客户端，专门为安卓 6 及以上的老设备做了适配。整个 App 在本地就能跑一套「计划 → 工具调用 → 总结」的离线 agent 引擎，不依赖网络；会话、工具、配置三大功能都在手机上直接用。程序一旦崩溃会自动跳到崩溃页，日志能一键复制发回开发侧。企业风格界面，支持个性化。

## 功能一览

### 四大功能页
- **会话**：列出所有 agent 会话，带运行状态徽章（运行中 / 已完成 / 失败），点进去可继续跑任务、查看完整的「计划 → 工具 → 总结」执行轨迹。
- **工具**：管理端侧可用的工具集（代码检索、文件操作、Shell 沙箱、HTTP、记忆等），行内开关即时生效，影响下一次任务执行。
- **配置**：调整模型、温度、最大 token、自动提交、工作目录等运行参数，保存后下次任务直接套用。
- **诊断**：一眼看清系统状态——会话总数、启用/停用工具数、当前模型、最近更新时间。

### 崩溃兜底（核心卖点）
- 全局未捕获异常处理：任意线程上的崩溃都会自动进入崩溃页，不会白屏或闪退。
- 崩溃页展示可读日志（时间、系统版本、设备型号、完整堆栈），底部提供「复制日志 / 分享 / 返回首页」三个按钮，方便把现场直接发回开发侧。

### 企业风格界面
- 统一的导航蓝配色，卡片式布局，顶栏品牌渐变，视觉克制、层级清晰。
- 深浅色双主题，跟随系统或手动切换。

### 个性化设置
- 深浅色主题、四种强调色、字号缩放、起始停留页、震动反馈、摇一摇抓取日志，全部持久化，下次启动沿用。

## 面向老设备做了哪些事

- **最低支持 API 23（安卓 6）**，目标 API 34；全程只用 Java，不引入 Kotlin。
- 功能页懒加载：首次点开才创建 Fragment，之后切换很轻。
- 所有磁盘读写都丢到后台线程，主线程不碰 IO。
- 会话页轮询在 Activity 销毁时正确清理，避免内存泄漏。
- 已规避 API 26+ 才有的方法（如 `String.join`），保证安卓 6 实机不崩。
- 开启大堆，降低老机 OOM 概率。


## 构建

需要 JDK 17 和 Android SDK（platform-34、build-tools 34）。本工程仓库源已配成国内镜像，拉依赖较快。

```bash
# 调试包
gradle :app:assembleDebug

# 发布包（带签名）
gradle :app:assembleRelease
```

产物在 `app/build/outputs/apk/` 下。签名配置写在 `app/build.gradle`；发布库存在 `gradle/`，正式上架前请替换成你自己的签名库并改掉密码。

## 关于本地引擎

会话页跑任务时，引擎会把当前启用的工具逐个执行一遍，拼成「计划 → 工具 → 总结」的轨迹显示在详情页。这套是离线、可查的；要接真实后端，把 `AgentBackend` 里的 `localEngine` 换成真实网络调用即可。

## 崩溃日志怎么用

崩溃页的日志包含时间、系统版本、设备型号和完整堆栈。点日志区，或点底部「复制日志」，都会把整段写进剪贴板，直接发给开发侧即可。
