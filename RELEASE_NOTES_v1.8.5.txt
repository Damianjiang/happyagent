Happy Agent v1.8.5 更新说明
============================
版本升级：1.8.4 → 1.8.5（versionCode 14 → 15，versionName 1.8.4 → 1.8.5）
纯 Java · 兼容安卓 6（API 23）及以上 · 端侧 agent 引擎

【卡死修复（重点排查）】
- GUI 读屏（gui_dump）原来在工作线程直接调 getRootInActiveWindow()，部分机型会挂起；
  现在读屏和点按/输入统一走「主线程 Handler + 带超时 latch」桥接，彻底防死锁。
- 后台读存档若抛异常，loaded 标记永不置位，界面每次要白等 5 秒；
  现在异常也兜底落位（读崩就用默认值），界面线程不再被拖住。

【新增功能（之前漏掉的，这次全部实现）】
- 语音朗读（TTS）：任务成功后可自动念出 AI 回复；设置页加「朗读回复」开关，
  设备没有语音包时静默跳过（诚实降级，不崩不卡）。
- 麦克风听写：聊天页输入栏新增麦克风按钮，点按用系统语音识别把话填进输入框，
  首次使用会申请录音权限（Manifest 加 RECORD_AUDIO，运行时申请）。
- 离线本地引擎升级：没配 Key 时不再只道歉，内置确定性小能力真实可用——
  直接发算式就本地算（如 128*37+9）、问时间/查存储/查电池/查设备/列文件。

【引擎优化（「引擎烂」这块）】
- 温度越界收口：温度滑条走到 2000 也不会让 OpenAI/Gemini 收到 20.0 而报 400，
  统一 clamp 到 0~2.0。
- 工具结果进模型前截断（保留头尾），长输出不再把上下文塞爆让模型乱走；
  界面 trace 仍保留全文。
- 任务最大步数可调（4~20，配置页可设，老存档兼容归一为 10）。
- 新增 file_delete / file_mkdir 两个工具（数据层早能，之前模型工具没给），
  三家供应商 schema/别名/分组/分发全接，系统提示词里注明删除需谨慎。
- http_get 截断响应时给出明确提示，不再无声吞掉。

【有功能没 UI 的问题（这次补齐界面入口）】
- 工具步骤行点按可展开全文（之前只显示一行省略，长输出看不到）。
- 会话列表露出每条会话的消息数。
- 诊断页新增「能力状态」卡：GUI 无障碍服务 / 角色卡字数 / TTS 开关 / 最大步数。
- 工具详情页子工具清单补上 file_delete / file_mkdir。
- 配置页露出「最大步数」设置项。

【UI 设计与布局（「比较垃圾」这块重做）】
- 输入栏图标全部自绘（图片/文件/麦克风），去掉系统旧图标，统一风格去 AI 味。
- AI 头像从空圆圈改成强调色 ✦ 星标。
- 聊天空状态改简洁引导（星标 + 一句话 + 次级说明），不再堆砌。
- 导航/返回/设置等图标改成跟随主题色，深浅两套都协调。
- 沿用 v1.8 设计系统：暖白纸感浅色 + 墨色暗色，5 套强调色，发丝线卡片不吃阴影。

构建校验：gradle assembleRelease 全绿；aapt2 versionCode=15 / versionName=1.8.5 /
minSdk=23 / targetSdk=34，新增 RECORD_AUDIO 权限；apksigner verify 通过；
发布包与源 APK 逐字节一致（SHA256 比对）。
