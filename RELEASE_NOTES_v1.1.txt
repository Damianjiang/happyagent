# Happy Agent 1.1

基于 v1.0 的新版本。以下为本次更新内容。

## 新增功能
- 本地 Web 服务：手机变本地 Web 服务器，电脑/手机浏览器打开即可跟智能体对话；可开关，运行时通知栏常驻并显示内网/外网地址与端口；网页端自动匹配手机或电脑、支持深浅色。
- 内置文件管理：「文件」页选择一个文件夹授权后，可浏览、编辑文件，并把文件直接发给智能体处理；授权由系统自动弹出，仅覆盖所选目录。
- 首次打开欢迎页：显示应用要点与「开源项目·完全免费，收费即属诈骗」警示，仅出现一次。
- 深浅色主题：整 App 真正支持暗色/亮色切换。

## 改进
- 工具页开关现在真正生效：可实时限制智能体能调用哪些工具。
- 震动反馈、摇一摇导出日志为真实可用功能。
- 模型连接失败自动重试：前 3 次各等 1 秒、之后每次等 2 秒，循环重连直到成功；用户可随时取消；密钥错误等确定性错误不会反复重试。
- 清理了若干「保存了却从不生效」的设置项，界面更简洁。
- 安卓 6 兼容加固（前台服务、通知通道、持久权限等按系统版本分支处理）。
