# Happy Agent 1.3

本次为功能与界面增强版：补齐工具能力、充实文件管理页、修好桌面图标、净化深浅色主题。

## 新增 / 修复
- **桌面图标统一为笑脸**：安卓 7+（API 26）用的自适应图标此前仍是旧版蓝色六边形，现在前景/背景/单色三层全部换成和回退位图一致的笑脸圆（黄圆+五官），安卓 6 / 7+ 看到的图标一致；并新增单色（monochrome）层，安卓 13+ 主题化图标下也规范显示。
- **工具能力扩充**（参考 operit 扩展文件工具）：在原有 读/写/列目录/信息/查找/grep 基础上，新增 `file_exists`、`file_move`（移动/重命名）、`file_copy`、`file_zip`（压缩）、`file_unzip`（解压），外加一个无副作用的 `time_now`（当前日期时间）工具。三套供应商（OpenAI / Google / Anthropic）的工具 schema 与本地分发同步更新，共 14 个可调用工具。全部纯 `java.io` / `java.util.zip`，不加新依赖，API 23 可用。
- **文件管理页充实**：未授权时不再只留一张卡片一大片空白，改为"选择文件夹"引导 + 三条能力清单（浏览目录 / 编辑文本 / 发给智能体）；已授权后顶部显示当前目录统计（文件夹数 / 文件数 / 总大小），并新增目录内"按名称过滤"搜索框（本地即时过滤，不重查 SAF）。
- **深浅色主题净化**：此前把品牌深蓝 `#1E40AF` 直接写死当文字色/图标色，深色模式下深蓝配深灰底对比度极差、显得"混色"。现改为走语义 token `?attr/colorPrimary`（亮=品牌蓝、暗=浅蓝 `#93C5FD`），亮色纯亮、暗色纯暗。

## 说明
- 版本升级：1.2 → 1.3（versionCode 3 → 4）。
- 新工具仅新增能力，老存档结构不变（工具开关仍以 `tool.*` 分组存，反序列化兼容）。
- 新增 `file_zip`/`file_unzip` 做了"沙箱越界"校验（解出的条目必须落在目标目录内），防 zip 滑出攻击。
- Happy Agent 为开源项目，完全免费；若你为它支付过费用，说明你被骗了。
