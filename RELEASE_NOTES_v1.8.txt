# Happy Agent 1.8

视觉与个性化大改：去 Material 官方味，重做成一套「暖白纸感（浅）+ 墨色（暗）」的设计系统，并补齐整套个性化设置。

## 新设计系统
- 配色从企业深蓝整套换掉，自定一套克制的纸感双色板：浅色=暖白底 #F6F5F2 + 墨色文字 #1B1B1B；暗色=近乎黑的墨色 #0E0E11（不用纯黑，防发闷）+ 分层靠极细发丝线而不是阴影。
- 卡片统一 14dp 圆角 + 发丝描边、零投影；按钮全 App 改成 10dp 圆角、非全大写、低阴影，去掉 Material 默认胶囊的「官方味」。
- 聊天气泡、发送键、头像、状态点、导航选中色全部改走 theme 属性，深浅色自动跟，不再写死。

## 个性化设置（新增）
- **强调色 5 选 1**：靛蓝 / 青绿 / 苔绿 / 砖红 / 琥珀。按钮、气泡、状态点、tab 选中色、发送键全 App 跟着走，切强调色即时重建。
- **主题三态**：跟随系统 / 浅色 / 暗色。替代原来的二值「深色模式」开关；老版二值键自动迁移，不丢数据。
- **会话字号**：标准 / 大 / 特大 三档，直接作用于聊天气泡。
- 智能体名字（配置页可改）现在会真正注入系统提示词——之前能改但引擎没用它。

## 设置页重做
- 整体按新设计语言重排：外观（主题/强调色/字号）→ 行为 → Web 服务 → 关于，卡片吃发丝线、不吃阴影。
- 关于卡版本号改成动态取包信息（之前写死 1.0），欢迎页同步。

## 顺手修掉一批问题
- 设置页顶栏返回箭头点了没反应 → 接上导航监听。
- 文件页 tab 选中色写死品牌深蓝，暗色下对比差 → 改走强调色。
- 会话空态那个大按钮会把屏幕撑成两半 → 改居中、不抢空间。
- 关于弹窗里过期的图标描述清掉。

## 兼容性
- 依旧纯 Java、minSdk 23（安卓 6）；全部颜色/布局走资源限定符 + theme 属性，暗色自动跟，不新增任何权限。
- 版本升级：1.7.1 → 1.8（versionCode 9 → 10）。
