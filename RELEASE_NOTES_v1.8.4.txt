# Happy Agent 1.8.4

引擎优化 + 把 README 里标"未实现"的功能做掉（GUI 自动化、角色卡/世界书），全部真接入，不做假实现。

## 引擎优化
- **工具步骤实时增量显示**：任务运行中，工具调用（`gui_*`/`file_*` 等）每发生一步就立刻滚动进聊天页，不再"跑完才一次性 dump"。结束才全量重建，避免重复。
- 运行中 trace 用 `CopyOnWriteArrayList`，界面轮询读快照，线程安全不卡主线程。

## 新增功能
- **GUI 自动化**：新增 `gui_dump`（读当前屏幕可点/可输入元素）/ `gui_click`（按文本点按）/ `gui_type`（向可输入框输入）三个工具，三家 schema/别名/分组/分发全接。底层是 `GuardService`（无障碍服务，主线程桥接 + 带超时防死锁），**诚实降级**：没在系统里开无障碍服务时工具返回明确提示，不假装能点。设置页「能力扩展」有状态显示 + 跳系统开启入口。
- **角色卡 / 世界书**：设置页「能力扩展」填一段设定，注入每次任务系统提示词的人设（`AgentBackend` 每次任务前从 Prefs 读，改了立即生效）。

## 兼容性说明
- GUI 自动化需用户在系统「无障碍」里手动开启服务（`GuardService`），未开启时三工具返回提示，不影响其它功能。
- 依旧纯 Java，minSdk 23（安卓 6）；无障碍相关全用 API 19~23 的老 API，无高版本调用。
- 版本升级：1.8.3 → 1.8.4（versionCode 13 → 14）。
