# Happy Agent 1.7.1

补丁更新：把工具说明与代码/文档对齐，弱模型照提示词能查到全部工具。

- **系统提示词补全**：`systemPrompt` 的「可用工具」清单原先漏了 `http_post` 和 `text_calc`（两者其实已在三家 function-calling schema、别名表、分发逻辑里接好）。这次把这两个补进提示词，模型照着提示词能一次查到所有可用工具，减少"以为没有这个工具"导致的试错。
- **工具页标签对齐**：`defaultTools` 里 `tool.http` 标签由「HTTP 抓取/抓取网页正文」改为「HTTP 请求/抓取网页 · 发 POST（可带 JSON 请求体）」；`tool.text` 标签加上「四则运算」，与 1.7 新增能力一致。
- **无行为/权限变更**：仅文案与标签修正，工具实现、门控、沙箱、API 23 兼容均未改动；老存档照常读取。
- 版本升级：1.7 → 1.7.1（versionCode 8 → 9）。
