# Happy Agent 1.8.1

补丁更新：把那些「引擎/工具/字段其实已经有了、但界面没露出来」的功能补齐，纯 UI 露出，不加新权限、不碰高版本 API。

## 补齐的「功能有、UI 没写」
- **聊天页可复制**：AI 回复气泡、工具调用输出各加一个复制入口，一键进剪贴板（之前只能干看，复制能力藏在系统长按里）。
- **工具详情列出子工具**：每个工具组（文件/查找/Shell/HTTP/文本/设备）在详情页直接列出引擎实际实现的一批子工具 + 参数示例（如 `file_edit {path, old_text, new_text}`、`http_post {url, body?}`），不再是只一个组名 + 开关。
- **诊断页补全**：
  - 运行时新增 温度 / 最大 token / 智能体名 / 运行中任务（是否 + 是否暂停）
  - 模型接入改为 **三家 Key 各自的状态**（OpenAI / Google / Anthropic 分别显示「已配置/未配置」），而不是只看当前供应商那一个
  - 新增「个性化」卡片：当前主题 / 强调色 / 会话字号，所见即所得

## 其它
- `ic_copy` 图标改成跟随主题色（之前写死一个灰，暗色下突兀）。
- 无行为变更、无新增权限；依旧 minSdk 23（安卓 6），纯 Java。
- 版本升级：1.8 → 1.8.1（versionCode 10 → 11）。
