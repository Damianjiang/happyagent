# Happy Agent 1.5

本次补齐端侧 agent 缺失的工具，并把代码注释/文档收敛到人写的工程风格。

## 新增工具（对齐 operit 工具全集，纯端侧可补的部分）
在 1.3/1.4 已有的文件工具（读/写/列/信息/存在/移动/复制/压缩/解压/查找/grep）和时间工具基础上，新增两组：

**文本 / 数据处理（`tool.text`）**
- `text_base64_encode` / `text_base64_decode`：文本 ↔ base64
- `text_url_encode` / `text_url_decode`：URL 编码 / 解码
- `text_json_get`：按点路径取 JSON 字段（如 `a.b.0.c`，支持对象与数组根）
- `text_upper` / `text_lower`：大小写
- `text_stats`：统计字符 / 行 / 词

**设备状态（`tool.system`，只读）**
- `system_device_info`：厂商/型号/API、可用内存、内部存储、网络类型、本地时间
- `system_battery`：电量、充放电状态、电池健康
- `system_storage`：可用/总量、有无外置存储
- `system_network`：Wi-Fi / 蜂窝 / 以太网，连接状态
- `system_clipboard_get` / `system_clipboard_set`：读 / 写剪贴板文本

OpenAI / Google / Anthropic 三套供应商 schema 与本地分发同步更新，端侧 agent 共 **26** 个可调用工具。工具页新增「文本 / 数据处理」「设备状态」两个开关。

> 未引入需新权限的系统控制类（改设置 / 装卸载 / Intent / 通知 / 定位 / 蓝牙）——那些违背「端侧 agent、不加新权限」的定位，且 operit 里是靠 `Tools.System` 桥接，这边没有对应原生桥，不做假实现。

## 兼容性
- 老存档升级后由 `AgentBackend.mergeDefaultTools()` 自动补齐新增的工具分组（默认开启），旧 `state.ser` 仍可正常读。
- 全部纯 `java` / `android.util.Base64` / `org.json` / 老系统 API（`Build`/`BatteryManager`/`StatFs`/`ConnectivityManager`/`ClipboardManager`），无 `java.nio.file`、无新依赖，API 23 可用。
